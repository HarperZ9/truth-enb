# Truth ENB Nexus media

These files are approved, text-free, abstract promotional brand art generated
with OpenAI image generation. They are not gameplay screenshots and must not be
presented as evidence of in-game visual quality.

Any Nexus Mods page that uses these images requires the `AI Media` tag. Do not
submit or use these images in the current Nexus Mods 25th Anniversary Mod Drive,
whose rules prohibit generated media.

All shader-quality claims, before/after comparisons, quality-tier comparisons,
and runtime feature demonstrations require clearly labeled real in-game
screenshots or captures.
